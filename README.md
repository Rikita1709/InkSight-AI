# Handwritten Text Recognition System

An AI-powered handwritten text recognition system that converts handwritten notes into editable digital text using OCR and Transformer models.

---

## Features

- Handwritten text recognition
- OCR using TrOCR
- OpenCV image preprocessing
- Editable digital text output
- Simple frontend interface
- Flask backend API

---

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Flask
- AI Model: TrOCR
- Image Processing: OpenCV

---

## Project Workflow

1. User uploads handwritten image
2. Backend preprocesses image
3. TrOCR model extracts text
4. Extracted text displayed on frontend
